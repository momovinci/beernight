# Beernight 웹 서비스 기획 스펙

## 서비스 개요

**Beernight**는 사용자가 입력한 질문과 답변자를 바탕으로 **질문-답변자를 랜덤으로 매칭해주는 재밌는 웹 게임**입니다.

설정한 질문만큼 카드를 선택하며 진행하고, 선택할 때마다 새로운 답변자 조합이 랜덤으로 나타나 예측 불가능한 재미를 제공합니다.

---

## 📱 화면 구성 (3단계)

### 1️⃣ 설정 페이지 (Setup Screen)

**진입 조건**: 앱 시작 시 최초 진입

**구성 요소**:
- **제목**: "게임 설정"
- **질문 입력 영역** (최소 1개 필수)
  - 동적 질문 입력 필드 (무한 추가 가능)
  - 각 질문마다 텍스트 입력 상자 + 삭제 버튼
  - "+ 질문 추가" 버튼

- **답변자 입력 영역** (최소 2명 필수)
  - 동적 답변자 입력 필드 (무한 추가 가능)
  - 각 답변자마다:
    - 사진 업로드 (이미지 파일 선택)
    - 이름 입력 텍스트 필드
    - 삭제 버튼
  - "+ 답변자 추가" 버튼

- **하단 액션 버튼**
  - "게임 시작" 버튼
    - 유효성: 질문 1개+, 답변자 2명+일 때만 활성화
    - 클릭 시: 입력 데이터를 상태에 저장 후 **게임 화면으로 전환**

**데이터 저장**:
```javascript
questions: ["질문1", "질문2", ...]
answerers: [
  { name: "이름1", photo: "base64 or blob" },
  { name: "이름2", photo: "base64 or blob" },
  ...
]
```

---

### 2️⃣ 게임 화면 (Game Screen)

**진입 조건**: 설정 페이지에서 "게임 시작" 클릭

**구성 요소**:
- **헤더**
  - 타이틀: "게임 진행 중"
  - 남은 카드 수 표시: "📍 남은 질문 N개" (전체 중 아직 선택하지 않은 개수)

- **카드 그리드**
  - 설정에서 입력한 질문 개수만큼 카드 렌더링
  - 각 카드:
    - **숫자 표시**: 1, 2, 3, ... (질문 번호)
    - **상태**: 미선택 (기본) / 선택됨 (클릭 후)
    - **상호작용**: 클릭 시 → **결과 화면으로 전환**
    - **중요**: 선택된 카드는 **다시 선택 불가능** (비활성화 상태로 표시)
  - 레이아웃: 그리드 (예: 3×N, 4×N, 등 반응형)

- **하단 액션 버튼**
  - "게임 리셋" 버튼
    - 클릭 시: 게임 상태 초기화 (선택 카드 리셋)
    - 효과: **설정 페이지로 돌아가며, 입력 필드는 모두 초기화됨**

**상태 관리**:
```javascript
usedQuestionIndexes: new Set([0, 2, ...])  // 선택된 질문 인덱스
currentQuestion: { text: "질문 내용", index: 0 }
```

---

### 3️⃣ 결과 화면 (Result Screen)

**진입 조건**: 게임 화면에서 카드 클릭

**구성 요소**:
- **헤더**
  - 타이틀: "매칭 결과!"

- **질문 표시 영역**
  - 선택된 질문 텍스트를 큼지막하게 표시
  - 예: "당신의 가장 자랑스러운 순간은?"

- **답변자 매칭 영역**
  - **2명의 답변자 카드**를 나란히 표시
  - 각 답변자 카드 구성:
    - 사진 (원형 또는 사각형 프로필)
    - 이름 (사진 아래)
  - **중요**: 매 결과 화면 진입 시마다 **2명이 새로 랜덤으로 선택됨**
    - 이전에 선택된 답변자가 다시 나올 수 있음
    - 같은 사람이 양쪽에 나올 수는 없음 (중복 제외)

- **하단 액션 버튼**
  - "다음 카드 선택" 버튼
    - 클릭 시: **게임 화면으로 돌아감**
    - 새로운 질문을 선택할 준비가 된 상태
    - 답변자는 상관없이 계속 랜덤으로 선택됨

**상태 관리**:
```javascript
currentQuestion: { text: "...", index: 0 }
currentAnswerers: [answerer1, answerer2]  // 랜덤 선택된 2명
```

## 🔄 데이터 흐름

```
설정 페이지
  ↓ (질문 + 답변자 입력)
  ↓ "게임 시작" 클릭
  ↓
게임 화면
  ↓ (카드 선택)
  ↓ 카드 클릭
  ↓
결과 화면 (질문 1개 + 답변자 2명 랜덤 매칭)
  ↓ "다음 카드" 클릭
  ↓
게임 화면 (미선택 카드만 남음)
  ↓ (반복)
  ↓
모든 카드 선택 완료 시
  ↓ "게임 리셋" 클릭하거나
  ↓ 앱 새로고침
  ↓
설정 페이지 (초기화됨)
```

## ✅ 유효성 검사 규칙

### 설정 페이지
- **질문**: 최소 1개 입력 필수
- **답변자**: 최소 2명 입력 필수 (단, 2명일 때 항상 같은 2명만 나옴)
- **사진**: 선택사항 (없으면 기본 아바타 또는 텍스트만 표시)
- **이름**: 필수 입력

### 게임 화면
- **카드 중복 선택**: 불가능 (선택된 카드는 비활성화)

### 결과 화면
- **답변자 중복**: 같은 사람이 양쪽에 나올 수 없음
  - 예: 2명 설정 시 항상 두 명 모두 나타남
  - 3명 이상 설정 시 중복 제외하고 랜덤 선택

## 🔧 기술적 고려사항

### 파일 업로드 처리
- 사진은 **base64로 인코딩**하여 메모리에 저장
- 또는 **Canvas/Blob API** 사용
- 로컬 스토리지 활용 가능 (세션 유지 필요 시)

### 랜덤 선택 로직
```javascript
function selectRandomAnswerers(answerers, exclude = []) {
  // 1. exclude 목록 제외
  // 2. 중복 없이 2명 선택
  // 3. 2명 이상이면 정렬 후 반환
}
```

### 상태 초기화
- "게임 리셋" 시:
  - `usedQuestionIndexes` 클리어
  - `questions`, `answerers` 초기화 (설정 페이지 상태로)
  - `currentView` = 'setup'

## 📐 UI/UX 원칙

- **버튼**: Tailwind로 스타일링, Beernight 토큰 컬러 사용
  - 주요 액션 (게임 시작): 핑크 (`#f90873`)
  - 보조 액션 (다음, 리셋): 블루 (`#4060ff`)
  - 위험 (삭제): 레드 (`#f73c3c`)

- **카드**: 흰 배경, 보더 0.5px, 둥근 모서리
  - 비활성화: 그레이 배경 (`#e4e4e7`)
  - 선택 시: 약간 더 진한 배경

- **반응형**: 모바일~데스크톱 모두 지원 (Tailwind 그리드)

## 📝 초기값 및 기본 설정

- **질문 초기값**: 1개 빈 입력칸 (선택적)
- **답변자 초기값**: 2개 빈 입력칸 (선택적)
- **카드 그리드**: 최대 3열 (모바일 1열, 태블릿 2열, 데스크톱 3열)
